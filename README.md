# mission-control
a web-based scoring, match management, and live rankings system for FIRST LEGO League Future Edition.

soon.. framework for all future junior FIRST championships (after FLL phases out..)

## stack

frontend: React + Vite + TypeScript + MUI \
backend: Hono \
database: SQLite + Drizzlev \
live updates: SSE \
shared rules: packages/rules

## ai decleration
ai was used strictly as a tool and a teacher in making this project. \
all ai used was NOT allowed to directly interact with the repo nor any of the files. \
every design choice and line written was primarily written by a human, except for ai: \
- being used to design and mostly create the frontend ui
- co-planning site and api architecture
- code proofreading & refactoring
- showcasing examples of how to implement features and the code needed + fill in the blanks
