# mission-control
a web-based scoring, match management, and live rankings system for FIRST LEGO League Future Edition.

## stack

frontend: React + Vite + TypeScript + MUI \
backend: Hono \ 
database: SQLite + Drizzlev \
live updates: SSE \
shared rules: packages/rules

## ai decleration
ai was used in making this project through:
- being used to design the frontend ui
- planning architecture
- code proofreading

all other code is human made.
